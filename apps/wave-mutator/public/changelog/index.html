Wave Mutator Free beta

Changelog

A public record of release milestones, practical improvements, and the current scope of the local sample-cleanup workflow.

  1. Current beta release

    v0.2.5

    October 24, 2026

    Corrected edit-history dependencies, partial exports, delivered peak levels, import cancellation, and playback cleanup.

    • Removing a Trim or Delete also removes dependent later edits, with explicit labels and full-chain Undo.
    • Partial ZIP results show exported and failed counts, list missing files in the manifest, and offer a separate retry ZIP.
    • Normalize the delivered channels and sample rate before WAV quantization.
    • Serialize imports, enforce queue limits across overlapping drops, and discard pending results on cancel or clear.
    • Stop playback when its file is removed and cancel delayed starts for removed audio.
  2. Beta release

    v0.2.4

    October 13, 2026

    Clearer preview states and separate cleanup and editing views, with more reliable audio delivery.

    • Renamed the free edition to Wave Mutator Free across the app, site pages, and local export labels.
    • Separated Quick Clean and Waveform Editor views, with explicit Original, Edited, and Cleaned previews.
    • Original playback now always uses untouched source audio. Editing is limited to the Edited state; Cleaned matches WAV delivery.
    • Corrected the fade-out direction and zero-millisecond trim padding.
    • Cleaned playback now includes WAV channel conversion, resampling, and bit depth, with matching output measurements.
    • Source rates are read before decoding; source metadata and rendered WAV metadata are shown separately.
    • 32-bit float WAV preserves headroom. Delivery setting changes invalidate existing previews.
    • Added browser audio regression tests for processing, decoding, WAV payloads, ZIP delivery, and montage export.
    • Turned the waveform into a time-ruler editor with separate channel lanes, drag selection, exact times, selection playback, and zoom-to-selection.
    • Added non-destructive Trim, Delete, Silence, Fade In, Fade Out, and Gain operations with removable edit history and undo/redo.
  3. Beta release

    v0.2.3

    September 7, 2026

    Simplified the first-run workflow around adding audio, choosing a delivery target, previewing cleanup, and downloading the result.

    • Replaced the delivery-profile dropdown with clear task-based target cards.
    • Moved specialist cleanup and export settings behind optional customization panels.
    • Collapsed pack QA until it is needed, while retaining batch, montage, and advanced analysis tools.
  4. Beta release

    v0.2.2

    September 5, 2026

    Introduced tier-specific branding to clarify the focused local sample-preparation workflow.

    • Updated the public name, browser metadata, search records, changelog, and supporting guides.
    • Existing links continue to use /tools/wave-mutator/ so bookmarks and shared URLs stay valid.
    • Aligned default pack names, settings exports, and local reports with the edition name.
  5. Current beta release

    v0.2.1

    August 21, 2026

    Added delivery profiles for recurring sample-pack, music-pack, game-SFX, and store-preview tasks.

    • Delivery Profiles now set practical cleanup, naming, export, pack, and preview defaults.
    • Preflight and export controls make the selected production target easier to review before rendering.
    • The workflow remains local: source audio is decoded, processed, and exported in the browser.

  6. v0.2.0

    August 20, 2026

    Introduced the public beta for preparing cleaner WAV files, ZIP packs, and short MP3 preview montages.

    • Added silence trimming, short fades, peak normalization, clipping warnings, and browser preview processing.
    • Added single-file WAV, ZIP queue, manifest, and MP3 montage export paths.
Current beta limits

Wave Mutator Free does not yet offer LUFS normalization, spectral editing, AI tagging, or full DAW-style repair. The tool is designed for clear, local preparation rather than replacement of a mastering or restoration suite.

Wave Mutator Free is a local-first Kreativ Sound browser tool.
