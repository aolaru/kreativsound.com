Preset Mutator Pro Changelog

A concise public record of improvements and fixes for the local-first tool that creates 32 Vital variants per run.

  1. Current release

    v0.4.9

    September 5, 2026

    Renamed the paid edition to Preset Mutator Pro.

    • Standardized the Pro name across Scratch, Preset, Audio, activation, metadata, and upgrade links.
    • Kept the existing Pro URL, licensing, generation, and ZIP export behavior unchanged.

  2. v0.4.8

    September 2, 2026

    Made the wider browser-tool line easier to reach from every Pro workflow.

    • Added a direct All tools path to Scratch, Mutate Preset, and Audio to Preset.
    • Kept the verified 32-variant workflow focused while making related tools and release information easier to discover.

  3. v0.4.7

    August 28, 2026

    Expanded the generation engine so repeated runs produce more distinct, balanced Vital preset packs.

    • Matched curated Velvet Ruins structures to the requested sound profile before pack generation.
    • Balanced every Scratch and Audio pack across four oscillator, texture, macro, and modulation topologies.
    • Added deterministic near-duplicate retries for Scratch, Audio, and Preset packs.
    • Added family-specific output, effect, and delay-feedback limits for more reliable Vital playback.

  4. v0.4.4

    August 27, 2026

    Corrected generated-preset exports so the selected direction is heard more faithfully in Vital.

    • Cleared inherited LFO and macro modulation routes from the family seeds.
    • Disabled unused seed oscillators, samples, filters, and side effects before export.
    • Kept the 32-variant Pro workflow focused on the selected direction.

  5. v0.4.3

    August 22, 2026

    Added a clearer public release record for the Pro tool.

    • Added a dedicated changelog linked from every Preset Mutator Pro workflow.
    • Made the changelog available offline alongside the rest of the app shell.
    • Added QA coverage to prevent the version history link from disappearing.

  6. v0.4.2

    August 21, 2026

    Unified the Pro experience across Scratch, Preset, and Audio modes.

    • Aligned the activation flow and key states across all three workflows.
    • Improved the source-ready states so the workspace remains focused before a file or direction is loaded.
    • Removed preview-sound controls so generated results stay clearly focused on exported Vital presets.

  7. v0.4.1

    August 21, 2026

    Established the paid Vital pack workflow.

    • Added 32-variant packs from Scratch, Preset, and Audio starting points.
    • Added local ZIP export for complete preset packs.
    • Kept access verification in the browser with signed purchase tokens.

  8. v0.4.0

    August 21, 2026

    Refined the Pro workflow around larger, usable preset batches.

    • Standardized the three starting modes for a more predictable generation flow.
    • Added a focused activation panel before the main workspace.
    • Strengthened browser-based QA for 32-pack generation and exports.
