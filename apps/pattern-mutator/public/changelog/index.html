Changelog

A concise public record of improvements and fixes for the free, local-first MIDI idea generator.

  1. Current release

    v0.1.1

    August 25, 2026

    Added a dedicated public changelog directly from the Pattern Mutator footer.

    • Made the current version and release history easy to find from the tool.
    • Added a searchable changelog route for future feature notes and fixes.

  2. v0.1.0

    August 25, 2026

    First public draft of Pattern Mutator.

    • Generated scale-aware melodies, basslines, chord patterns, and arpeggios.
    • Added 1–32 bar pattern lengths, controlled mutation locks, browser audition, and Standard MIDI export.
    • Kept generation and export entirely local in the browser.

Kreativ Sound browser tool for controlled MIDI pattern generation.
