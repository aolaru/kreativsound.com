Preset Mutator Lite Changelog

A concise public record of improvements and fixes. The tool remains free, local-first, and focused on playable Vital starting points.

  1. Current release

    v0.4.7

    September 2, 2026

    Made the wider browser-tool line easier to reach from every Lite workflow.

    • Added a direct All tools path to Scratch, Mutate Preset, and Audio to Preset.
    • Kept the focused local workflow intact while making related tools and release information easier to discover.

  2. v0.4.6

    August 28, 2026

    Expanded the generation engine so each run begins from more distinct, usable Vital structures.

    • Added controlled oscillator, layered, noise-bed, focused, and delay/reverb-led starting architectures.
    • Expanded safe preset mutation into active OSC 3, noise, distortion, compressor, flanger, and phaser controls.
    • Made Audio respond to source duration as well as tone, transients, movement, and width.

  3. v0.4.3

    August 27, 2026

    Corrected generated-preset exports so the selected direction is heard more faithfully in Vital.

    • Cleared inherited LFO and macro modulation routes from the family seeds.
    • Disabled unused seed oscillators, samples, filters, and side effects before export.
    • Added export QA to prevent generated patches from inheriting those routes again.

  4. v0.4.2

    August 22, 2026

    Added a clearer public release record for the free tool.

    • Added a dedicated changelog linked from every Preset Mutator Lite workflow.
    • Made the changelog available offline alongside the rest of the app shell.
    • Added QA coverage to prevent the version history link from disappearing.

  5. v0.4.1

    August 21, 2026

    A clearer, more focused generation workflow across Scratch, Preset, and Audio.

    • Removed generated preview sounds so results are not mistaken for the exported Vital presets.
    • Improved result-set exploration with fresh sets and clearer generated-result controls.
    • Added practical examples and direction keywords to speed up first-use decisions.

  6. v0.4.0

    August 21, 2026

    Refined the free workflow around three generated Vital variants.

    • Standardized language across all three modes: Scratch, Preset, and Audio.
    • Added focused PRO links without placing licensing or checkout controls in the free tool.
    • Strengthened browser-based QA for exported preset data and the app shell.

  7. v0.3.0

    August 20, 2026

    Introduced a more tactile way to shape generated results.

    • Added the Mutation Amount macro control for setting how far variants move from the source or intent.
    • Kept detailed controls available as optional fine tuning instead of competing with the main workflow.
    • Improved keyboard and pointer interaction for the knob control.

  8. v0.2.0

    August 19, 2026

    Established the three free ways to start a Vital preset.

    • Scratch creates variants from musical intent.
    • Preset mutates an existing local .vital file.
    • Audio maps a short local sound source into preset directions.
