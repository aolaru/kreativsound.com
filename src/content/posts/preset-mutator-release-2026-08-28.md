<p><strong>Preset Mutator Free v0.4.6</strong> and <strong>Preset Mutator PRO v0.4.7</strong> make the Vital workflow more useful when you need several genuinely different starting points, not small variations of the same idea.</p>

<p>The update keeps the product’s scope deliberately narrow: the tool still runs locally in the browser, uses curated seed data and clear rules rather than cloud generation, and exports files you can finish inside Vital.</p>

<h2>What changed</h2>
<ul>
  <li>Generation now begins from a broader set of Vital structures, including controlled oscillator, layered, noise-bed, focused, and delay/reverb-led directions.</li>
  <li>Preset mutation can safely use more of Vital’s active sound-shaping controls, including OSC 3, noise, distortion, compressor, flanger, and phaser parameters.</li>
  <li>Audio to Preset responds more closely to duration, transients, movement, width, and tone, so short source sounds create more useful directions.</li>
  <li>PRO pack generation balances across distinct structures and retries near-duplicates before delivering the 32-preset ZIP.</li>
</ul>

<h2>Which version should you use?</h2>
<p>Use <strong>Free</strong> when you want three quick Vital ideas and individual downloads. Use <strong>PRO</strong> when the session needs a wider 32-variant set with a complete ZIP export. Both use the same From Scratch, Mutate Preset, and Audio to Preset workflow.</p>
